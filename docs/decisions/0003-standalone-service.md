# 0003. 独立サービスとして提供する

- 日付：2026-10-19
- 状態：承認

## 背景

記憶は Web、Windows、配信、ゲームなど複数の窓口と、自律行動や会話を担う複数のエージェントから共有される。サービス間は名前空間・API レベルで疎結合にする方針である。

## 決定

- 本リポジトリは HTTP API を持つ独立サービスとし、利用側には薄いクライアントを提供する。
- 利用サービスの本体には組み込まない。

## 影響

- 窓口やエージェントの追加時に記憶側の変更が不要になる。
- 応答経路にネットワーク呼び出しが入るため、音声会話ではレイテンシ予算を決めて検索件数を調整する。
