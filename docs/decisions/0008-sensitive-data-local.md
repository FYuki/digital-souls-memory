# 0008. 機微判定はローカルで行い、それ以外の処理はクラウドも使う

- 日付：2026-10-19
- 状態：承認（機微判定の実施場所は 0016 で Core に置き換え）

## 背景

LLM はクラウドとローカルを併用する。機微情報の分類は完全にローカルで行う方針である。抽出・内省・審査・記述変換にもLLMを使う。

以下の取り込み時の判定と常時稼働環境に関する記述は当初の決定である。[0016](0016-sensitivity-labeled-by-caller.md) により、現在は Core が登録前に判定し、Memory は判定済みのラベルを必須として受け付ける。クラウドへの送信制限は維持する。

## 決定（当初）

- 機微ラベルは Turn の取り込み時にローカルモデルで付け、クラウドで処理する前に必ず済ませる。
- 機微な Turn はクラウドに送らず、抽出・内省はローカルで行うか、マスクした形でだけ送る。
- 機微判定以外の処理はクラウドを使ってよい。各処理のモデル配置はインフラのスペックを見て決める。
- 審査エージェントは内省と別のモデル・別のコンテキストで動かす。

## 検討した案

- **抽出はローカル、内省と記述変換はクラウドに固定する**：インフラのスペックが決まる前にモデル配置を固定しないため、機微判定以外はスペックを見て決めることにした。

## 影響

- 機微判定は取り込みごとに常時走るため、常時稼働する環境に置く必要がある。
