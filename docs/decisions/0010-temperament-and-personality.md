# 0010. 人格を気質（記述）と性格（Big Five 10アスペクト）に分ける

- 日付：2026-10-19
- 状態：承認

## 背景

変化しない人格と、経験によって変わる性格を同じ仕組みで扱うと、一貫性と成長のどちらかが損なわれる。LLMの振る舞いは数値より文章と実例で決まるが、ドリフトの測定と変化量の管理には数値が要る。

## 決定

- Temperament（気質）は変化しない人格を記述文で持つ（0004 の登録APIで管理）。
- PersonalityProfile（性格）は Big Five Aspect Scales（DeYoung, Quilty & Peterson 2007）の10アスペクトを0〜1の数値で持ち、そこから記述文を生成する。
- 応答時にLLMへ渡すのは記述文だけで、数値はドリフト測定と ChangeBudget の判定に使う。
- 記述文は数値と変換器のバージョンから再生成できる派生物とし、変換時に気質を入力に含める。
- 初期値は次の手順で作者が用意し、登録APIで登録する。
  1. 作者が性格を自由記述で書く。
  2. LLM が10アスペクトの数値を推定する。
  3. 気質と推定値を与えたキャラに質問票へ回答させ、採点結果と推定値のずれを確認する。
  4. 作者が数値を確定する。
  5. 確定値を記述文に変換し、記述文から再推定して元の値に戻るか確かめる。
- 代表発話（VoiceExemplar）の初期セットは30〜50件程度を推奨値とするが、必須にはしない。

## 影響

- 登録時に一度だけ整合チェック（典型的な状況への応答を生成し、口調と気質との矛盾を審査エージェントが確認）を行う。
