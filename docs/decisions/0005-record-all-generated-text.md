# 0005. キャラが生成した文はすべて記録し、届いた範囲は追記で記録する

- 日付：2026-10-19
- 状態：承認

## 背景

音声会話ではキャラの発話が割り込みで途中終了することがある。どの本文を相手に渡すかは記憶サービスの外の責務である。生成した文は、話されなかった部分も回答のために考えた本人の思考として存在したとみなす。

## 決定

- キャラが生成した文は、話されなかった部分も含めて全文を Turn として登録する。
- 相手にどこまで届いたかは、窓口からの報告を DeliveryReceipt（status: full／partial／none, spoken_until）として別レコードで追記する。Turn は書き換えない。

## 影響

- キャラは「言うつもりだったが伝わっていない」内容を区別して扱える。
- DeliveryReceipt の報告は任意で、届かなければ全文が伝わったかどうかは不明として扱う。
