# 0016. 機微判定は登録前に呼び出し側（Core）で行い、Memory は判定済みの Turn だけを受け付ける

- 日付：2026-10-20
- 状態：承認（0008 の機微判定の実施場所を置き換える）

## 背景

0008 では、Memory が Turn の取り込み時にローカルモデルで機微ラベルを付けるとしていた。0015 で Memory の呼び出し元が Core だけになり、Core には機微分類器とその評価がすでにある。

## 決定

- 機微判定は、Turn を Memory に登録する前に Core がローカルで行う。
- Memory の Turn 登録 API は機微ラベルを必須とし、ラベルのない Turn は登録を拒否する。ラベルがないことを「機微でない」とはみなさない。
- Memory は受け取ったラベルに従って処理先を振り分ける。機微な Turn はクラウドに送らず、抽出・内省はローカルで行うか、マスクした形でだけ送る（G6）。
- Memory は機微分類器を持たない。

## 検討した案

以下は今回の決定と代替構成の比較説明であり、過去に各案が明示提案されたことを示す記録ではない。

- **Memory が取り込み時にローカルで判定する（0008 当初の決定）**：Core と Memory の両方に常時稼働の分類器を置くことになり、判定結果も二重になるため置き換えた。
- **ラベルがなければ Memory 側で機微とみなして受け付ける**：判定漏れが静かに通るため、明示的に拒否する。

## 影響

- Memory は Core の判定を信頼する。判定の品質は Core の評価で担保する。
- Turn に機微ラベル（sensitivity）と判定に使った分類器の版を持たせる。
