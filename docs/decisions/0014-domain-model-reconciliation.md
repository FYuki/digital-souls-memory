# 0014. 2つの調査を突き合わせ、ドメインモデルを6つのコンテキストに分ける

- 日付：2026-10-19（2026-10-20 にドメインモデルから検討経緯を移設）
- 状態：承認

## 背景

記憶と内省の設計について、Claude と Codex がそれぞれ調査を行った（[原文と要約の比較](../research/raw-vs-summary-memory.md)、[認知科学からの設計](../research/reflection-and-memory-cognitive-science.md)）。両調査は「原文を正本にし、要約は索引。内省は根拠付きで撤回可能な派生物。人格は低速で版管理」という骨格で一致した。

一致した点：

- 原文は不変の正本、要約・事実・embedding は検索用の派生物（Claude：LongMemEval・SeCom・Zep／Codex：LongMemEval・言語依存記憶研究）
- 内省は事実と分離し、根拠リンク・確信度・版を必須にする（Claude：Generative Agents・ExpeL／Codex：Generative Agents・Reflexion）
- 事実は上書きせず、valid_from／valid_to で時間変化として持つ
- 原文削除時は派生グラフをたどって内省・人格更新まで失効させる

## 決定

骨格を保ったまま、Codex 側の観点を次のとおり取り込む。

| 観点 | Codex の主張と根拠 | 反映先 |
| --- | --- | --- |
| 合成的裏付け | 内省の上に内省を積むと同じ原文を何度も数えて確信度が膨らむ。独立証拠数は原文の葉の数で数える | 不変条件 R3 |
| 信頼階層 | 情報源を Tier A〜F に分け、推論や内省が直接発言に自動昇格しない | Epistemics、不変条件 G1〜G3 |
| メタ認知の較正 | LLM の自己申告確信度は当てにならない（Koriat 1997）。確信度は複数特徴から合成する | 不変条件 G1〜G3 |
| 反芻の抑止 | 内省は具体的・証拠参照型にし、複合トリガーとクールダウンで頻度を抑える（Watkins 2008） | ReflectionTrigger、不変条件 R5 |
| 遅い自己 | 層ごとに学習率を変え、1回の変化量に予算を設け、独立証拠3件以上で特性変更 | ChangeBudget、不変条件 P3 |
| 記憶汚染 | 通常の対話だけで長期記憶に悪意ある記録を注入できる（MINJA, arXiv 2503.03704）。記憶は命令として扱わない | 不変条件 G4 |
| 原言語の保持 | 一人称・敬語・終助詞・呼称は関係性の情報。英語要約を正本にしない | Turn の言語属性、不変条件 E3 |
| 過去の信念の保持 | 一貫性とは「なぜ変わったか説明できること」。当時の信念も残す | Belief の版管理、IdentityHistory |

構造は Evidence・Memory・Reflection・Identity・Voice・Governance の6コンテキストに分け、依存は Evidence を最下層とする一方向にする。

## 検討した案

- **1つの多態的な memory object（Codex 案）**：raw・semantic・reflection・self_schema を同じオブジェクトに入れる。不変の原文と可変の派生物を同じ型に置くと「原文は変更禁止」を型で守れないため不採用とし、集約を分けた。
- **代表発話ストアを持たない（Codex 案）**：Codex は言語形式の保持までだった。RoleLLM と REVERIEMEM の結果から VoiceExemplar を残した。
- **特性を数値だけで持つ（Codex 案）**：数値はドリフト測定に便利だが、LLM の振る舞いは数値より文章と実例で決まる。数値と記述文の両方を持たせた（0010）。
- **閾値・重み・学習率を固定値として採用**：Codex 自身が「チューニング開始点」と明記しており実証値ではない。"Do AI Personas Grow?"（arXiv 2608.06485）は経験による人格変化が弱く不安定だと示すため、変化を起こす閾値より変化の持続確認を重視し、数値は ChangeBudget の設定値に外出しした（0011）。
- **短期状態を持たない（Codex 案）**：Codex には CharacterState に当たる層がないため、前回案の CharacterState を残した。
- **臨床事実とキャラの内省を別ストアにする（Codex 案）**：想定用途外のため、Trust Tier の一般規則に含めて個別の層は作らない。

## 影響

- 不変条件はコンテキストの頭文字（E, M, R, P, V, G）で番号づける。
- 閾値は運用中に評価指標を見て調整する。
