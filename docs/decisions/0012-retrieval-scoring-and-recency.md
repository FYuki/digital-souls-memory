# 0012. 検索は複合スコアとし、忘却は新しさの項の減衰としてだけ表現する

- 日付：2026-10-19（2026-10-20 改訂）
- 状態：承認

## 背景

原文は消さない方針（0001）のため、忘却は削除では表現できない。新しさの影響を大きくすると、古いが重要な記憶が想起されにくくなる。検索されるたびに新しさを更新すると、よく検索される記憶ほど検索されやすくなる自己強化が起きる。

## 決定

- 検索スコアは、意味の近さ・語彙一致・新しさ・重要度・自己関連度・信頼度の加重和とする。係数の合計は1とし、新しさの係数は0.1以下にする。
- 忘却は新しさの項の減衰としてだけ表現し、原文と派生記憶は消さない。VerbatimAnchor と Commitment は減衰・再強化の対象外とする。
- 新しさの起点は、出来事の時刻と最後に再強化された時刻の新しいほうとする。再強化は同じ内容が新しい Turn で再び話題になったときだけ行い、検索されただけでは更新しない。
- 再強化の判定は、窓口ごとの非同期の裏処理で、派生記憶の抽出（ゲート M5 経由）時に行う。新しい Turn から記憶を抽出するときに既存の DerivedMemory と照合し、同じ内容の言い直しか補強（MemoryRelation の extends、または同一の Fact の再表明）と判定したら、その DerivedMemory を再強化する。
- 再強化の対象になる根拠は、そのキャラの知覚範囲（M6）の Turn のうち、キャラ自身以外の actor の発話と observation だけとする。キャラ自身の発話では再強化しない。
- 再強化では last_reinforced_at をその Turn の occurred_at に更新し、その Turn を source_turn_ids に追加する。処理した時刻は使わず、occurred_at が既存の last_reinforced_at より古ければ時刻は更新しない。
- 内容が更新された場合（MemoryRelation の updates：事実が変わった）は再強化ではなく、旧事実の valid_to を閉じて新事実を追加する（P4）。

## 検討した案

旧ドメインモデルの E3 では、既存の忘却曲線（Ebbinghaus）を残すかを検討した。最終決定では忘却を検索スコアの新しさの項だけで表現した。忘却曲線で記憶を削除する案があったという記録はない。

- **検索されるたびに新しさを再強化する**：背景で述べた自己強化を避けるため採用しない。
- **キャラ自身の発話でも再強化する**：想起で渡した記憶をキャラが口にすることで再強化されると、検索による自己強化と同じ循環が起きるため不採用。キャラ自身の発話の抽出・検索（M3）と、再強化の対象は分ける。

## 影響

- 提供した内容は [0018 の ProvisionRecord](0018-provision-record.md) に残る。提供しただけでは last_reinforced_at を更新しない。
