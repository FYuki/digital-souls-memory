# 0012. 検索は複合スコアとし、忘却は新しさの項の減衰としてだけ表現する

- 日付：2026-10-19
- 状態：承認

## 背景

原文は消さない方針（0001）のため、忘却は削除では表現できない。新しさの影響を大きくすると、古いが重要な記憶が想起されにくくなる。検索されるたびに新しさを更新すると、よく検索される記憶ほど検索されやすくなる自己強化が起きる。

## 決定

- 検索スコアは、意味の近さ・語彙一致・新しさ・重要度・自己関連度・信頼度の加重和とする。係数の合計は1とし、新しさの係数は0.1以下にする。
- 忘却は新しさの項の減衰としてだけ表現し、原文と派生記憶は消さない。VerbatimAnchor と Commitment は減衰の対象外とする。
- 新しさの起点は、出来事の時刻と最後に再強化された時刻の新しいほうとする。再強化は同じ内容が新しい Turn で再び話題になったときだけ行い、検索されただけでは更新しない。

## 検討した案

旧ドメインモデルの E3 では、既存の忘却曲線（Ebbinghaus）を残すかを検討した。最終決定では忘却を検索スコアの新しさの項だけで表現した。忘却曲線で記憶を削除する案があったという記録はない。

- **検索されるたびに新しさを再強化する**：背景で述べた自己強化を避けるため採用しない。
