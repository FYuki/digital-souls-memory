# 0019. Phase 1 の削除は作者だけが行い、出典を直接たどる範囲で連鎖させる

- 日付：2026-10-20
- 状態：承認

## 背景

削除要求は作者・ユーザー本人・視聴者から出る可能性がある。完全な連鎖削除（G5）には、内省・信念・人格版まで含む ProvenanceGraph が必要で、これは Phase 2 以降に作られる。一方、Phase 1 でも誤登録や機微情報の取り消しのために削除は必要である。

## 決定

- Phase 1 では、作者だけが DeletionRequest を出せる。
- Phase 1 の連鎖は、派生記憶の source_turn_ids と提供記録の ID 参照を直接たどる範囲とする。他の原文だけで支えられる派生記憶は再計算し、支えを失うものは失効させる。cascade_result を記録する。
- ProvenanceGraph による内省・信念・人格版・代表発話までの連鎖は Phase 3 で実装する。
- 視聴者・ユーザー本人からの削除要求の窓口は Phase 3 で設計する。

## 検討した案

- **削除を Phase 3 まで持たない**：誤登録や機微情報を取り消せないため不採用。

## 影響

- Phase 2 で内省を導入する時点では、削除時に内省が失効しない期間が生じる。Phase 3 までの間、内省の根拠が削除された場合は手動で確認する。
