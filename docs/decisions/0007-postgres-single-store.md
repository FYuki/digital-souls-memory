# 0007. ストレージは PostgreSQL（pgvector）一本とし、Docker で運用する

- 日付：2026-10-19
- 状態：承認

## 背景

原文・派生記憶・内省・人格版をトランザクションで一貫して扱いたい。ベクトル検索専用DB（Qdrant）の併用も検討した。

## 決定

- PostgreSQL に一本化し、ベクトル検索は pgvector で行う。
- 日本語全文検索は pg_bigm と PGroonga を比較して選ぶ。
- 埋め込みモデルは多言語モデル（bge-m3、multilingual-e5 など）をローカルで比較して選ぶ。
- 開発・運用とも Docker を使う。
- Qdrant への切り替えは、次のどちらかを満たしたときに Retriever ポートの裏で行う。
  - ベクトル検索の p95 レイテンシが音声応答の予算を超え、索引のチューニングでも戻らない。
  - ベクトル索引のメモリが DB サーバーを圧迫し、書き込みに影響する。

## 影響

- ベクトル化の対象を派生記憶とキャラが反応した Turn に絞ることで、索引の規模を抑える。
