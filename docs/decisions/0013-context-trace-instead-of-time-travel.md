# 0013. 時点再現クエリは持たず、発話ごとの ContextTrace で追跡する

- 日付：2026-10-19
- 状態：承認（ContextTrace は 0018 の提供記録に置き換え）

[0015](0015-core-and-memory-boundary.md) により、本記録の「利用サービス」「利用側」は Core を指す。

## 背景

利用サービスは常に最新の Card と人格を使う方針である。一方、ChangeBudget を運用中に調整するには、ある発言がどの人格版・どの記憶から出たかを追える必要がある。

ContextTrace とそれを用いる監査は [0018](0018-provision-record.md) で置き換えた。時点再現クエリを持たない方針と人格の版の履歴は維持する。

## 決定（当初）

- 時点を指定して過去の応答を再現するクエリは持たない。応答は常に現在有効な版を使う。
- キャラの各発話に ContextTrace（参照した記憶・原文、気質と性格の版、動機、代表発話、プロンプトテンプレートの版、モデル）を残す。
- 人格の版の履歴は、rollback と変化の説明のために保持する。

## 検討した案

- **時点 t で有効な版だけを参照して過去の応答を再現できるようにする（旧 M4）**：利用側は常に最新の人格を使う方針で、再現クエリの需要がないため不採用。

## 影響

- 監査・デバッグは ContextTrace と IdentityHistory を突き合わせて行う。
