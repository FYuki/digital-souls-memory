# 想起の入力長による遅延増加の診断（2026-10-28）

件数依存の増加は長文queryの語彙SQL評価が主因。1039文字query・長文本文のp50は100件1,224.6ms→1000件4,224.1msとなり、PR #116の約1,223→4,216msを再現した。語彙SQLの中央値は312.9→3,049.4msで、全体増分約3,000msの約91%に相当する（異なる中央値の差による概算）。長文本文では最終JSONを1,500トークンへ収める反復処理も独立した大きな負荷となる。rerankは20件固定でも入力token数で増える。修正と採否決定は行っていない。

## 内訳
